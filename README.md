# AΞGISTRUST: Deepfake Protection & OSINT Intelligence
## Sviluppo e Implementazione di un'Architettura Modulare Enterprise

Questo repository contiene l'elaborato tecnico dedicato alla progettazione di **AΞGISTRUST**, un sistema avanzato di cybersecurity progettato per la protezione dell'identità digitale e l'analisi biometrica multimodale in ambienti aziendali.

---

## 🛡️ Core Features del Sistema

Il progetto analizza l'integrazione di diverse tecnologie di difesa:

* **Protezione Deepfake:** Validazione biometrica basata su **rPPG** (remote Photoplethysmography) per il rilevamento del battito cardiaco via video e analisi del *Liveness Detection*.
* **Intelligence OSINT:** Metodologie avanzate per la scansione di database pubblici e Dark Web per il monitoraggio dei data leak.
* **Analisi Fonetica:** Sistemi di identificazione vocale per prevenire attacchi di spoofing audio.
* **Performance Enterprise:** Analisi dei tempi di risposta e affidabilità dei moduli (fino al 99.1% di precisione nel Deepfake Shield).

---

## 📊 Specifiche Tecniche
L'elaborato include tabelle prestazionali e validazioni dei parametri biometrici:
- **Analisi rPPG:** Per il blinking e la micro-circolazione facciale.
- **Soglie di Errore:** Analisi fonetica con EER (Equal Error Rate) < 0.5%.
- **Infrastruttura:** Modelli predittivi per l'analisi comportamentale aziendale.
